# Project Farming RPG

A modular Farming & Adventure RPG prototype developed with **Unreal Engine 5.8**, using **C++ and Blueprints**.

This project is a hands-on learning environment focused on gameplay programming, technical game design, and maintainable game architecture.

## Project Goals

- Develop modular gameplay systems using C++ and Blueprints.
- Apply object-oriented programming principles and clean architecture.
- Explore gameplay mechanics from both engineering and game design perspectives.
- Build interconnected systems within a farming and adventure RPG.

## Implemented Systems

### Interaction System (v0.1)

- Interface-based interaction architecture.
- Component-based player interaction logic.
- Nearby interactable detection using sphere overlap.
- Contextual target selection based on distance and camera direction.
- Line-of-sight validation.
- Dynamic interaction prompts.
- World-anchored interaction UI using screen projection.
- Event-driven target change notifications.

## Getting Started

1. Clone the repository.
2. Install Git LFS and run `git lfs pull`.
3. Open `Project_Farming_RPG.uproject` with Unreal Engine 5.8.
4. Build the C++ project using a compatible development environment.
5. Open the interaction development map to explore the current prototype.
